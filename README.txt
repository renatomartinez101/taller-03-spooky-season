CÓMO EJECUTAR
1. Clona el repositorio https://github.com/renatomartinez101/taller-03-spooky-season con git clone.
2. En Eclipse, selecciona File > Import > General > Existing Projects into Workspace.
3. Selecciona la carpeta clonada e importa SpookySeason. Usa un JDK 21.
4. Abre src/taller03/Main.java y ejecútalo con Run As > Java Application.
5. Usa la consola de Eclipse y conserva Monstruos.txt y Registros.txt en la raíz del proyecto.
